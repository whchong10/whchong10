Movie Rankings 13/10/2026

In this exercise, I created an interactive scatter plot using my personal Letterboxd movie watching diary to visualise my movie ratings throughout 2026.

First, I exported my data from Letterboxd and imported the diary.csv file into Python using Pandas. I cleaned the dataset by removing unnecessary columns and movies watched before 2026. I created a new category to distinguish between movies watched at the cinema and at home, based on the tags in my diary. I used Plotly Express to create a scatter plot, with the watched date on the x-axis and movie ratings on the y-axis. I used different colours to represent the viewing categories and added hover information to display details about each movie. I added date buttons and a range slider to allow viewers to interactively explore different periods of my movie watching history.
