Title Letterboxd Movie Multiplot
Summary The interactive multiplot visualises my personal movie watching diary through 2026. It consists of 4 graphs showing my movie ratings over time, rating distribution, top 5 genres, and the release decades of the movies I've watched.

The main scatter plot displays each movie I've watched and is plotted according to the watch date and my rating on a 5-star scale. Movies are colour coded by viewing location, either watched at the cinemas or watched at home. The interactive date selector allows viewers to switch between monthly and the entire period of 2026.

The 3 bar charts provides additional information about my movie watching habits, showing the distribution of ratings, the 5 most watched genres, and the number of movies watched by release decade.

Hovering over individual points shows additional information about each movie.
Data Sources Chong, W. H. (2026). Letterboxd rating diary [Personal dataset].

The data was collected from my personal movie watching diary on Letterboxd
Mapping Letterboxd Rating Diary (Scatter Plot)

x-axis: Watched date
y-axis: Ratings
Blue: movies watched at home
Red: movies watched at cinemas
Hover information: Displays the movie title, release year, rating, tags, and watched date
Date Buttons: Allows the viewer to adjust the period of the date range displayed
Range Slider: Allows the viewer to adjust the date range displayed

Rating Distribution (Bar Chart)

x-axis: Ratings on a 5-star scale
y-axis: Number of movies
Bar height: Number of movies given each rating
Hover information: Displays the number of movies at each rating

Top 5 Genres (Horizontal Bar Chart)

x-axis: Number of movies
y-axis: Movie genres
Bar height: Number of movies belonging to each genre
Hover information: Displays the number of movies in each genre

Films by Release Decade (Bar Chart)

x-axis: Release decade
y-axis: Number of movies
Bar height: Number of movies released in each decade
Hover information: Displays the number of movies from each decade
Important Notes Data was obtained by exporting my Letterboxd, via the Data tab of Account settings. In the zip file that was given, only diary.csv was used.

The data was processed using Python and Pandas before being visualised with Plotly. Date(date that I added the movie to my diary) and Letterboxd URL was removed in this process. Movies before 2026 were removed as well.

Movies containing the tag "cinema" were classified as "Cinema", while all the others were classified as "At Home".

Most movies had multiple genres, they were counted under each applicable genre. Only the top 5 genres were shown.

Movies were grouped into decades based on their release year.

The 3 bar charts show the number of movies watched for each rating, genre, and release decade. These are based on movie counts rather than average ratings.
